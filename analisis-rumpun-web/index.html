Buka profil peneliti di Bohrium, tekan Ctrl+A lalu Ctrl+C, kemudian tempel (Ctrl+V) ke kolom Research Focus di atas — tag akan disaring otomatis dari tempelan itu. Menempelkan tag saja (dipisah koma) juga bisa. Bookmarklet tersedia untuk pemakai lanjutan:
Kenapa kadang tidak bisa terhubung langsung? SINTA dan Google Scholar memblokir akses lintas-situs dari browser (CORS + anti-bot) — kebijakan mereka, bukan kerusakan tool. Karena itu ada dua mode: Mode A mencoba jalur otomatis (relay + API terbuka ORCID/OpenAlex/Crossref); Mode B selalu berhasil di komputer mana pun.

🗂️ Sumber Data yang Dipakai

Secara default semua sumber dipakai. Centang sumber yang tidak ingin diikutkan dalam analisis, atau klik tombol untuk memakai semua sumber. Berlaku untuk Mode A (Otomatis); Mode B memakai data yang Anda tempel.
Kecualikan:

🚀 Mode A — Otomatis

Sistem menelusuri SINTA, Google Scholar, ORCID, OpenAlex, Crossref, PDDikti secara online. Status tiap sumber tampil live; sumber yang gagal dilewati.

📋 Mode B — Salin-Tempel Cerdas selalu berhasil, offline

1. Klik tombol database di bawah → buka profil dosen. 2. Di halaman profil: Ctrl+A lalu Ctrl+C. 3. Tempel (Ctrl+V) di sini — boleh gabungan SINTA + Scholar. Metrik, afiliasi, NIDN & judul diekstrak otomatis dan digabung dengan hasil Mode A bila ada.

🏷️ Pedoman Kata Kunci SDGs (Universitas Airlangga · 68 hal · tertanam penuh)
